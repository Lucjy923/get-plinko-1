How the peg board changes each round

The board is built as a triangle of pegs, with each row wider than the one above it. A ball hits each peg and shifts left or right, repeating that movement until it reaches one of the bottom pockets. The more rows you choose, the more times the ball can change direction before landing.

Because the path is built from repeated left-or-right bounces, most Plinko ball results cluster near the center, while edge pockets stay rare. That pattern is why the game feels balanced: common pockets pay less, while uncommon outer pockets can pay much more.
